# v0.3.0 Release Design

## Goal

Release the nine local profile-discovery commits as `simple-subagents` v0.3.0 on GitHub, while leaving the local `suggestion-box.md` file unpublished and uncommitted. npm publication remains a manual follow-up performed by the maintainer.

## Changes

- Add `/suggestion-box.md` to `.gitignore` so the local notes file remains local.
- Update `package.json` and `package-lock.json` from version 0.2.0 to 0.3.0.
- Commit the release metadata with message `chore: release v0.3.0`.
- Create annotated Git tag `v0.3.0`.
- Push `master` and `v0.3.0` to `origin`.

## Verification

Before committing or pushing:

- Run the TypeScript typecheck.
- Run the complete test suite.
- Inspect Git status and the release diff to ensure `suggestion-box.md` is excluded.

After pushing:

- Fetch/check the remote branch and tag to confirm both resolve to the local release commit.
- Confirm npm still reports v0.2.0 until the maintainer publishes v0.3.0.

## npm Handoff

Provide the maintainer with commands to authenticate, perform a dry run, publish the public package, and verify npm's `latest` version.
